# わたしの余白

iPhoneで使う、月10万円の支出記録アプリです。毎月25日〜翌月24日を1期間として集計し、25日に予算が10万円に戻ります。残金の繰り越しはありません。過去の支出は残ります。日付は利用端末の現地日付を使います。

## 開発

Node.js 18以上（テスト用）、Python 3（開発サーバー用）。外部パッケージの導入は不要です。

```sh
cd /workspace/my-first-project
npm test
npm start
```

開発サーバーは8000番ポートで起動します。実運用では静的ファイルをHTTPSで公開してください。GitHub Pagesなどの静的ホスティングで動作します。サーバー側の処理やAPIキーは不要です。`tests/`、`package.json`などの開発用ファイルは公開に不要です。

## iPhoneで使う

1. HTTPSで公開したURLをSafariで開きます。
2. 「共有」→「ホーム画面に追加」を選びます。
3. ホーム画面から開き、金額・日付・任意のメモを入力します。

一度オンラインでアプリの保存が完了すれば、オフラインでも記録できます。データはブラウザのlocalStorageに保存され、サーバーには送信しません。ログイン、端末間同期、自動バックアップはありません。公開URL自体にアクセス制限はありませんが、支出データは各端末内に保存されます。プライベートブラウズは避けてください。Safariのデータ削除や端末故障で失う可能性があるため、「データの保存とバックアップ」からJSONを定期的に書き出してください。Safariとホーム画面アプリの間でデータが共有されない場合もJSONで移行できます。読み込みは既存データを置き換えます。

## 検証

`npm test`で25日の切替、年越し、うるう年、残高計算、予算超過、バックアップの入力検証を確認します。iPhone実機でのホーム画面追加・オフライン起動・ファイル保存は別途確認が必要です。

## 単一HTMLでのプレビュー

右側のファイルプレビューなど、別ファイルのCSSやJavaScriptを読めない場所では `preview.html` を開いてください。スタイルと処理を内蔵しています。ソース変更後は `npm run preview` で再生成します。プレビューでブラウザ保存が制限されている場合は「試用モード」と表示し、一時的に入力を試せます。この場合は閉じたり再読み込みすると入力が消えます。JavaScript自体が無効なプレビューでは操作できません。公開用のアプリでは保存失敗時に記録を成功扱いせず、エラーを表示します。通常のHTTPS公開には `index.html` と関連ファイルを使ってください。


## GitHub Pagesでの公開

GitHub PagesのSourceは **GitHub Actions** です。`main` ブランチへの変更で `.github/workflows/deploy-pages.yml` が起動し、テスト・ビルド後に `_site/` のアプリ用ファイルだけを公開します。開発用ファイルや試用版の `preview.html` はサイトに配信しません。Actionsの「Publish budget app」から手動実行もできます。

公開先は `https://yosukemasonhashimoto.github.io/my-first-project/` です。支出データは利用端末のブラウザに保存され、GitHubには送られません。公開前のプレビューに入力した試用データは、公開URLには自動では移行されません。

`npm run build` でローカルにも公開用の `_site/` を生成できます。別途準備した `gh-pages` ブランチは現在の公開元ではありません。
